🎬 CineLenz
🎯 Point at a poster. Get the rating from IMDB.

CineLenz is a Chrome extension that lets you identify any movie or TV show poster on the web — and now, any mentioned title — without leaving the page.

✨ Features
🖼️ Drag-select a poster → on-device OCR (Tesseract.js) reads the title, no image ever leaves your browser
🎬 Highlight any text (a comment, a caption, a headline) → click the 🎬 Rate button that pops up → instant rating card
⭐ Pulls ratings, plot, genre, and poster art from OMDb or TMDB (your choice, your API key)
🔒 100% offline OCR — works even with a spotty connection, and nothing is sent to a third-party server unless you opt into the cloud OCR fallback
🎨 Dark/light card themes, sticky-cursor mode, alternate-year picker for remakes/reboots (Dune '84 vs '21, etc.)
🚀 How to Use
🌐 Works on Chrome and Edge
⚙️ Switch to Developer Mode
📦 Load Unpacked
🔑 Obtain FREE API Key from OMDB & TMDB
🍿 Enjoy
🛠️ How it Works
⌨️ Hold Ctrl + Alt + Z
🖱️ Drag a box around a poster
🎯 Release
⭐ Get the movie/TV show rating

Or, just highlight a title anywhere on the page.

🙏 Big Thanks to IMDB, OMDB & TMDB.
